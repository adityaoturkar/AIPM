# PM Prompt Library

A curated collection of AI prompts for Product Managers — covering the full product lifecycle from discovery to data analysis.

## Purpose

This library helps PMs get more value from AI assistants (Claude, ChatGPT, Gemini, etc.) by providing battle-tested prompts for common PM workflows. Each prompt is designed to be copy-paste ready, with clear placeholders you can swap out for your context.

## How to Use

1. Browse the category that matches your current task
2. Copy the prompt
3. Replace `[BRACKETED PLACEHOLDERS]` with your specifics
4. Paste into your AI assistant of choice
5. Iterate — add follow-up prompts or adjust based on your output

## Prompt Format

Each prompt follows this structure:

```
### Prompt Title
**Use when:** [Scenario description]
**Output type:** [What the AI will return]

---
[The prompt text with [PLACEHOLDERS]]
```

## Contributing

Contributions welcome. To add a prompt:
1. Fork this repo
2. Add your prompt to the relevant category file following the format above
3. Open a pull request with a brief description of when the prompt is most useful

## Tips for Better Results

- **Be specific with placeholders** — the more context you give, the better the output
- **Iterate** — treat the first output as a draft; follow up with clarifying questions
- **Combine prompts** — chain discovery prompts into strategy prompts for end-to-end workflows
- **Adjust tone** — add "Write this for a technical audience" or "Keep this executive-level" to any prompt
